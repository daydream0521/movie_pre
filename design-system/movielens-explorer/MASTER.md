# MovieLens Explorer 设计体系

## 产品与依据
README.md 将产品定义为推荐系统课堂演示，app.py 已包含概览、原理实验室、电影推荐、实验结果、概念过渡五页。受众是课堂学生与演示讲解者；主要任务是理解评分、相似度与预测依据。平台为桌面优先、兼容手机的 Streamlit Web。

## 视觉方向
电影评分研究台：深蓝灰工作区、琥珀色操作重点、青色算法对照。矩阵与真实数据承担视觉中心，电影条目使用安静的纯色片头与衬线片名，不引入海报网络依赖。

字体：Segoe UI、Microsoft YaHei、PingFang SC，使用本地字体保证离线演示；电影片头使用 Georgia。标题 29–42px、分区 18px、正文 16px、辅助文字 13–14px；数值使用等宽数字。间距以 4/8px 为基础，面板内距 16–24px，分区间距 28px。圆角控件 5px、单元格 3px；无装饰阴影。

## 布局与组件
保留左侧原生导航，正文最大 1280px，左对齐标题与说明。页头为琥珀色竖线加标题；指标以低调表面分组，不加渐变。复用 src/ui.py 的 hero、kpi_row、movie_card、matrix_table、note、section 与原生 Streamlit 控件。Plotly 图表复用算法颜色，不改数据、指标、筛选与推荐计算。

布局：导航 | 标题与用途 → 数据摘要 → 矩阵 / 图表与解释 → 详细数据。手机端使用原生列堆叠，缩小外边距，分区说明换行。

## 交互
按钮至少 44px 高；保留原生键盘操作并提供可见焦点。目标格使用问号、隐藏评分使用虚线，状态不只依赖颜色。尊重 reduced-motion，不加入自动入场动效；保留随机用户、算法切换、步骤、对比与折叠行为。

## Frontend Design 审查结论
基于现有教学用途，去除蓝紫渐变横幅、统一大圆角卡片、悬浮位移动效和大写页头装饰。保留深色工作环境，辨识度集中于评分矩阵的琥珀 / 青色编码及电影条目排版，避免加入营销式首屏。

UI UX Pro Max：已应用技能中的平台适配、字体层级、语义色、焦点、触达尺寸与响应式规范；安装目录 scripts 是失效的路径占位文件，未能运行自动推荐脚本，以上为根据项目内容人工确定的最终规范。
